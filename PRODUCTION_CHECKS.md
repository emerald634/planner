Развёртывание, миграции рабочих БД, настройка BotFather/Nginx и перезапуски на VPS
не выполнялись. Параметры VPS взяты из присланного владельцем вывода read-only команд.

- `planner/backup.py` — SQLite Backup API, integrity/foreign keys, SHA256,

- `planner/ops.py` — read-only проверка баз, трёх привязок и текущего доступа.
- `deploy/planner.env.example` — подтверждённые пути, свободный при проверке порт

- `deploy/planner-compose.sh` — точный проект/файл Mini App, работа с существующим

- `deploy/package_release.py` — архив по allowlist без рабочих файлов бота,
  секретов, БД, node_modules и demo.
- `tests/test_planner_production.py` — проверки миграции, трёх ролей, резервирования,
  восстановления, неизменности отчётов, доступности и состава архива.

Набор тестов использует временные БД и искусственный токен, без запросов к
реальным Telegram/Bitrix. В tests есть предупреждение библиотеки Starlette о
будущем переходе тестового клиента на httpx2; текущие тесты проходят, зависимости
старого бота из-за этого не менялись. Права 600 для новой БД проверяются условно
на POSIX; локальная Windows-проверка не подтверждает ownership на Linux. Проверка
нового файла UID/GID/режима включена в инструкцию после запуска на VPS.

Сравнены SHA256 до/после подготовки: **без изменений** `.env`, `access.db`,
`compose.yaml`, основной `Dockerfile`, `bot.py`, `config.py`, `bitrix.py`,
`distribution.py`, `requirements.txt`. Значения секретов не выводились.
